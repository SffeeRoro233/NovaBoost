# 🚀 Nova

**A powerful PC optimization tool designed to help improve your computer's performance.**

Nova is a PC optimization project focused on system tweaks and performance improvements. This is the first public release, and more features and improvements are planned for the future.

## ⚙️ Requirements

Before running Nova, make sure you have the following installed:

- **Python** — The latest available version of Python is required.
- **Windows PC** — Nova is designed for Windows.

### 🐍 Python Installation

1. Download the latest version of Python from the official website: https://www.python.org/downloads/
2. Run the installer.
3. **IMPORTANT:** Make sure to check **"Add Python to PATH"** during installation.
4. Finish the installation and launch Nova.

> ⚠️ **Important:** Python is currently required to run Nova. We are working on making the application executable without requiring a separate Python installation. This requirement will hopefully be removed in a future update.

## 📥 Getting Started

1. Download or clone this repository.
2. Install the required version of Python.
3. Follow the instructions provided with the project to launch Nova.

## 🛠️ Development

Nova is still evolving. Features, optimizations, and usability improvements may be added in future releases.
